# AI JSON Type Definitions

Use these generated JSON files to verify the exact Zoom Video SDK Web API before
writing code. They represent `@zoom/videosdk` version `2.5.0`, generated by the
official `zoom/videosdk-web` repository on 2026-08-10.

## Source Priority

1. Use the application's installed `node_modules/@zoom/videosdk/dist/types/*.d.ts`
   files when available.
2. Use the matching file in `types-json/` when the application also uses 2.5.0,
   or when doing package-independent exploration.
3. Use prose references for workflows and constraints, not to invent API names.

If versions differ, report the mismatch and treat the installed declarations as
authoritative.

## How To Query

Start with `types-json/index.json` to find a module. Read only the relevant
module, then inspect declarations by name or kind. `types-json/schema.json`
defines the JSON format; `types-json/summary.json` provides the package export
summary.

```bash
jq '.version, .modules[] | select(.module == "media")' \
  references/types-json/index.json

jq '.declarations[] | select(.name == "Stream")' \
  references/types-json/media.json

rg -n 'peer-video-state-change|attachVideo' references/types-json
```

Never assume a matching text hit is callable. Check the declaration's kind,
signature, parameters, return type, source file, and parent interface.

## Version Drift

Do not silently use a 2.5.0 method in an older project. Check the installed
version first:

```bash
npm ls @zoom/videosdk
node -p "require('@zoom/videosdk/package.json').version"
```

When upgrading, compare the installed `.d.ts` declarations with these JSON files
and update implementation code, tests, CSP/browser requirements, and this skill
together.
